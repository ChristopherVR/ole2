01 / Quick start

Install the package

Import the public functions and types from the package root. The reader returns named directory entries and stream bytes.

npm install @christophervr/ole2
Parse a compound file
import {
  ENTRY_TYPE_STREAM,
  Ole2ParseError,
  parseOle2,
} from '@christophervr/ole2';

try {
  const file = parseOle2(arrayBuffer);
  const streams = file.entries
    .filter((entry) => entry.type === ENTRY_TYPE_STREAM)
    .map((entry) => entry.name);
  const wordBytes = file.getStream('WordDocument');
} catch (error) {
  const message = error instanceof Error ? error.message : String(error);
  console.error(
    error instanceof Ole2ParseError ? 'Invalid OLE2 file:' : 'Could not read OLE2 file:',
    message,
  );
}

parseOle2 accepts an ArrayBuffer. getStream returns Uint8Array | undefined.

02 / Build

Write named streams

buildOle2 writes a minimal version 3 compound container from a map of names to bytes. It returns an ArrayBuffer.

Round-trip a stream
import { buildOle2, parseOle2 } from '@christophervr/ole2';

const streams = new Map([
  ['Example', new TextEncoder().encode('hello')],
]);
const bytes = buildOle2(streams);

const parsed = parseOle2(bytes);
const example = parsed.getStream('Example');
if (!example) throw new Error('Example stream is missing');
const message = new TextDecoder().decode(example);

Optional arguments are a 16-byte root CLSID and a mini-stream cutoff (default 4096).

03 / Legacy Word

Read and edit main-body text

Use these helpers with the bytes of a complete Word 97–2003 .doc file. Paragraph indexes start at zero.

Read paragraphs
import { readOleDocParagraphs } from '@christophervr/ole2';

const paragraphs = readOleDocParagraphs(docBytes);
if (paragraphs === undefined) {
  throw new Error('Unsupported or unreadable .doc file');
}
console.log(paragraphs);
Edit safely
import { writeOleDocParagraphEdit } from '@christophervr/ole2';

const edited = writeOleDocParagraphEdit(
  docBytes,
  0,
  'Updated paragraph text',
);
if (edited === docBytes) {
  throw new Error('This edit was not supported');
}
// Save `edited` as the updated .doc file.

A successful edit returns new bytes. If the file or edit is unsupported, the original byte array is returned unchanged.

04 / Legacy Excel

Preview the first worksheet

readOleXlsGrid reads a bounded view of the first BIFF8 worksheet. Its rows contain cells with display text and a numeric flag.

Numeric and string cell writers return new bytes when an edit is applied. They return the original byte array unchanged when the target cannot be safely edited.

Read and update a cell
import {
  readOleXlsGrid,
  writeOleXlsNumericCellEdit,
} from '@christophervr/ole2';

const grid = readOleXlsGrid(xlsBytes, 30, 12);
if (!grid) throw new Error('No readable BIFF8 worksheet');
console.log(grid.sheetName, grid.rows[0]?.cells);

const edited = writeOleXlsNumericCellEdit(xlsBytes, {
  row: 0, col: 0, value: 42,
});
if (edited === xlsBytes) {
  throw new Error('This cell edit was not supported');
}

05 / Legacy PowerPoint export

Build a binary .ppt file

The PowerPoint viewer and other consumers share the same binary serializer. Pass a neutral WDeck model with dimensions in EMU, slide shapes and picture data.

The serializer handles text, shapes, pictures, notes, embedded objects and optional legacy RC4 encryption. Viewer-specific conversion and rendering stay in the PowerPoint package.

Create a blank legacy presentation
import { buildPptFile } from '@christophervr/ole2/legacy-ppt-writer';

const bytes = await buildPptFile({
  widthEmu: 9144000,
  heightEmu: 5143500,
  slides: [{ shapes: [] }],
  pictures: [],
});
// Write bytes to a .ppt file.

05 / Shared document properties

Edit metadata across legacy Office files

Read and update existing SummaryInformation text properties in DOC, XLS, PPT, Visio and Publisher containers. Edits must fit the existing property slot and use Windows-1250 through Windows-1258 or UTF-16. Other compound-file bytes stay unchanged.

The local file demo includes property editing and downloads. Visio drawings and Publisher publication pages are not yet decoded or editable.

Update an existing document title
import {
  readLegacyOfficeMetadata,
  writeLegacyOfficeMetadata,
  inspectLegacyVisio,
  inspectLegacyPublisher,
} from '@christophervr/ole2';

console.log(readLegacyOfficeMetadata(bytes));
const edited = writeLegacyOfficeMetadata(bytes, 'title', 'New title');
if (edited === bytes) console.log('Unchanged or unsupported edit.');

// Format-specific binary header inspection:
console.log(inspectLegacyVisio(bytes));
console.log(inspectLegacyPublisher(bytes));

05 / Format detection

Detection reports the support level

identifyLegacyOffice reads CFB stream names and returns a format, support level, stream list, and explanation. It does not parse every format it can identify.

DOC · XLS

Partial support: main-body text for legacy Word and a bounded first-sheet preview plus constrained cell edits for BIFF8 Excel.

PPT · Visio · Publisher

PowerPoint binary export and record primitives are shared with the presentation viewer. Visio and Publisher have binary-header inspection and standard document-property editing; drawing and publication-page editing are not supported.

OLE2 streams

The container reader lists and reads named streams. Building a CFB container does not create valid content for every Office format.
