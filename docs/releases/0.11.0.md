# 0.11.0

DOC character runs expose optional `directUnderline` and can replace an existing
exclusive direct `sprmCKul` operand with `none`, `single` or `double`. Inherited,
missing, shared, opaque and stale run operands refuse without mutation. Native
Word 16 comparisons cover single-to-double-to-none-to-single, native save/reopen
and byte-exact restoration, retaining all other captured character/paragraph
formatting, text, styles, stories and counts.

Existing XLS BIFF8 boolean/error cells can become finite numbers or plain strings
through `parseXls(bytes).sheets[index].cell(row, col).value`. Selected XF, other
cells, original SST aliases, opaque streams and supported pointer-bearing records
are preserved. Missing cells, formulas, clearing, malformed records and unsafe
relocation refuse atomically. Six native Excel 16 cases pass explicit normal
open, save/reopen and unchanged-field comparisons; RepairMode was unavailable.
The library retains saved formula caches and requests consumer recalculation.

The 0.10.1 VSD exact-decoded-length compression and PPT ownership safeguards are
retained. No native VSD transform admission is added. Native text coverage remains
the declared two-fixture matrix; drawing/rendering, master/group/style evaluation
and complete legacy parity remain separate gaps. These APIs extend existing-file
preservation rather than creating complete DOC/XLS models or new documents.
