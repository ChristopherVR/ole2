# 0.12.0

PPT text atoms now expose bounded direct character runs with UTF-16 spans,
`runsStatus`, `runsDiagnostic` and existing literal font sizes. Eligible uniquely
owned inline text boxes can replace a two-byte font-size operand through
`run.directFontSizePoints`. No style insertion, inherited formatting resolution,
run splitting, notes rich-run editing or general character-format writer is
added. Model identity maps keep bulk reads linear while refreshing retained
handles after supported edits. Native PowerPoint font edits and save/reopen
pass unchanged-field comparisons against an unchanged-save control; both saves
normalize the same six notes-shape IDs.

Binary Visio v11 pages expose `topLevelShapeIds` and shapes expose
`childShapeIds`, with `shapeOrderIssue` diagnostics when order is unresolved.
This corrects the previous physical-order assumption on a broader owned native
two-page fixture with a group, master, style and layers. Flat shape arrays remain
unchanged for lookup compatibility, and child coordinates remain local. The
reader resolves owner-scoped ShapeList/ShapeId mappings with bounded resources,
explicit malformed-input outcomes and byte-exact no-op preservation.

This release retains DOC/XLS additions and VSD/PPT safety gates from 0.11.0.
It adds no native VSD transform admission, master/style/ShapeSheet evaluation,
hidden secondary geometry or full drawing renderer. Native references establish
declared captured semantics; rendering and complete legacy parity remain gaps.
